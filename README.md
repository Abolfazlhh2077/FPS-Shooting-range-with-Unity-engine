# FPS-Shooting-range-with-Unity-engine
an sniper shooting range in FPS view made in unity as a side project to learn game development with this engine.
THIS GAME FEATURES:
- 5 challenges from easy to very hard
- realistic bullet balistics, including the effects of gravity and wind.
- realistic recoil system implemented with procedural animations.
- double view aiming system
- realistic scope view made with render texture to create a picture in picture and tunneled view effect.
